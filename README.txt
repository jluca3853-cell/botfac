BOT FARM + VENDAS
1. Extraia o ZIP.
2. Renomeie .env.example para .env e preencha os dados.
3. Abra o CMD na pasta.
4. npm install
5. node index.js

Comandos: /painelfarm, /farmhistorico, /painelvendas, /vendashistorico
As vendas sao registradas direto no MySQL, sem aprovacao.
Nunca compartilhe seu TOKEN ou senha do MySQL.
